# Indulge design evidence

## Direction

The owner approved an original soft-form 3D cartoon world after providing a
small sofa-and-character image as a quality benchmark. That benchmark is stored
under `references/` for internal comparison only and must not ship in the app or
be traced.

The implementation direction combines:

- `directions/soft-form-stage-a.png` for causal object-by-object scene assembly;
- `directions/soft-form-stage-c.png` for the continuous Now-to-Possible world
  morph;
- `directions/soft-form-stage-b.png` only as an exploded animation and modularity
  study.

All three direction comps were generated for this project with OpenAI's built-in
image generation tool. They are composition and craft references, not literal
screenshots or production assets.

## Production rule

The app uses original procedural or authored 3D geometry. Third-party stock art
is not copied into the product. Any later sourced asset must retain its license,
author, source URL, and attribution requirement beside the imported file.
