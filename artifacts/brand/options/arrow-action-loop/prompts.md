# Arrow and action logo exploration

Mode: built-in image generation, using the One Degree concept as a visual
reference. The phrase lockup was typeset separately as deterministic SVG so its
wording remains exact.

Shared brief: make daily repetition obvious through a circular arrow, place a
visible action or person on that routine, and show a clear changed direction
after one Cherry choice. Keep the symbol simple, rounded, and legible at 29 px.

- **A — Action Changes the Loop:** three action tiles sit on a circular routine;
  the Cherry tile changes the loop into an outward arrow.
- **B — Person Makes One Small Move:** a minimal Cherry person moves from the
  daily loop onto a gently rising arrow.
- **C — One Daily Action Compounds:** repeated action marks sit on the loop; the
  final Cherry action changes the radius and subsequent direction.

The accompanying lockup uses the exact text `break the loop.` below the Indulge
wordmark.
