# Indulge icon exports

- `options/indulge-sprout-mark-v4-1024.png` is the currently selected icon
  source.
- `indulge-app-icon-512.png` is a convenient brand preview.
- `favicon-64.png` and `favicon-32.png` are reusable web favicon exports.
- The shipping 1024px opaque source lives in
  `Indulge/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`.
- `archive/` preserves the previous open-loop icon and favicon exports.

The selected concept was created with built-in image generation. Its circular
routine contains repeated actions; one Cherry action redirects the path into a
horizontal exit that becomes a sprout, avoiding the gendered reading of the
previous diagonal-arrow silhouette. The exact-text brand lockup is available at
larger sizes with the line **break the loop.** The older arrow lockup remains under
`options/arrow-action-loop/` as exploration history only; it is not the current
distribution symbol. The App Store icon remains type-free and opaque.
