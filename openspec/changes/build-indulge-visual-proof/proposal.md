## Why

Indulge’s core promise is only credible if a user’s choices visibly and
beautifully assemble a fuller life around one persistent character. Before
building Screen Time plumbing or the complete product, the team needs a native
iPhone visual proof that establishes the soft-form 3D world, causal motion, and
the emotional present-to-possible transformation at production quality.

## What Changes

- Create a runnable native SwiftUI iPhone app using an original modular
  RealityKit scene rather than copied stock art or a flat animation mockup.
- Implement one abstract adult character assembled from reusable, independently
  animated soft-form parts.
- Implement a modular watching-TV scene: floor stage, sofa, television, lamp,
  phone, and detachable companion props including a neutral wine-glass proof.
- Let a fake-data onboarding choice physically spawn the furniture, re-pose the
  character, and settle the scene with authored spring timing and haptics.
- Add a scrub-able Now ↔ Possible transformation that preserves the indulgence
  while expanding the world with reading, walking, creating, and restoration
  objects.
- Demonstrate object-added completion, weekly scene morph, and graduation beats
  using the same scene-state system.
- Define a curated 20–30-item indulgence scene catalog assembled from a compact
  vocabulary of reusable poses, furniture clusters, prop sockets, and transition
  recipes rather than bespoke one-off animations.
- Provide Reduce Motion, VoiceOver descriptions, Dynamic Type, increased
  contrast, and deterministic preview/test states from the start.
- Keep Apple Screen Time APIs, persistent user data, notifications, widgets,
  extensions, production Rive assets, substance recommendations, and clinical
  behavior out of this visual-proof change.

## Capabilities

### New Capabilities

- `modular-life-scene`: A data-driven 3D life scene that composes a persistent
  character, activity furniture, hand props, and possible-life objects from an
  explicit scene state.
- `cinematic-choice-motion`: Causal, interruptible animations that turn a user
  choice into object arrival, character re-posing, scene morphing, and tactile
  feedback.
- `indulgence-scene-catalog`: A scalable content contract for roughly 20–30
  indulgence recipes and compatible user-declared companion props.
- `accessible-visual-proof`: A complete fake-data proof flow that remains
  understandable, operable, and emotionally coherent with native accessibility
  settings including Reduce Motion.

### Modified Capabilities

None.

## Impact

- Adds a new local native iOS project and app target inside this independent
  repository.
- Uses SwiftUI, RealityKit, and other Apple frameworks available in the installed
  Xcode toolchain; no production third-party dependency is required for the
  visual proof.
- Adds original generated direction comps and later original procedural or
  authored 3D assets, each with provenance recorded in the repository.
- Establishes the scene-state and motion contracts that later onboarding,
  persistence, Significant Hobbies activity data, and Screen Time extensions
  will consume without implementing those systems yet.
- Records substance-related companion props as neutral user-declared context;
  the catalog never recommends pairings or presents clinical guidance.
- Does not create a backend, upload user data, deploy, publish, or make App Store
  changes.
