# Indulge 0.1.0 (Build 3)

## What is ready to test

- A cohesive 12-question visual onboarding with 24 authored indulgence choices.
- Masculine and feminine scene continuity across the complete onboarding.
- Life, Trade, and History as the complete customer navigation.
- One persisted daily trade with explicit replacement, start, and finish.
- Three honest outcomes: made room, chose the indulgence, or another day.
- A causal completion scene and History populated only from completed trades.
- Local-first storage, optional Privacy Lock, and all-data deletion.
- Dark Mode in the daily app, Dynamic Type, increased contrast, VoiceOver
  semantics, and a crossfade-only Reduce Motion path.
- Optional future-life card creation through Image Playground when supported.

## Boundaries

- No Focus tracker, Screen Time enforcement, app-switch monitoring, remote AI,
  analytics SDK, web view, Cloudflare runtime, account wall, or subscription.
- Private CloudKit is configured for eligible signed builds but cross-device
  synchronization is not claimed until two-device verification is complete.
- This candidate is intended for internal TestFlight only. It is not submitted
  for App Store review or external beta testing by the upload action.
