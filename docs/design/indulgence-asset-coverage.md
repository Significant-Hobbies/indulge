# Indulgence asset coverage

No indulgence may appear in the production selector until all four columns are
complete: selector artwork, scene role, arrival, and Reduce Motion state.

Each production scene state also requires equivalent feminine and masculine
character plates. Both variants share framing, scene capability, and animation;
the app never infers presentation from the selected indulgence.

The launch catalog uses seven reusable base environments and specific object
clusters so combinations remain tractable.
